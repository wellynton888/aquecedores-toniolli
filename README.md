# Aquecedores Toniolli — site institucional

## Arquivos
- `index.html`: conteúdo e estrutura do site.
- `style.css`: cores, layout e responsividade.
- `script.js`: menu para celular e links do WhatsApp.
- `imagens/logo-toniolli.jpg`: logotipo enviado pela empresa.
- `imagens/desidratador.jpg`: foto do desidratador enviada pela empresa.

## Antes de publicar
1. Abra `script.js`.
2. Troque `5546999999999` pelo WhatsApp real da empresa, usando somente números e incluindo 55 + DDD + número.
3. Revise os textos e confirme se todas as descrições correspondem aos serviços e produtos reais da empresa.
4. O logotipo e a foto do desidratador enviados por você já estão na pasta `imagens/`. As fotos dos aquecedores a pellet, lenha e cavaco ainda podem ser adicionadas quando você as enviar. As imagens de fundo decorativas são carregadas do Unsplash pela internet.

## Testar no computador
Abra `index.html` no navegador. Para uma experiência melhor, abra a pasta no Visual Studio Code e use a extensão Live Server.

## Publicar grátis no GitHub Pages
1. Crie ou entre em uma conta em https://github.com/.
2. Crie um repositório novo, por exemplo `aquecedores-toniolli`.
3. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
4. No repositório, entre em **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)`; salve.
7. Aguarde a publicação. O GitHub mostrará o endereço do site na própria página Pages.

## Observações
- O número de WhatsApp no código é apenas um exemplo e precisa ser substituído.
- O site não inclui sistema de loja, cadastro de clientes ou painel administrativo.
- O endereço público do GitHub Pages normalmente segue o formato `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Página exclusiva Titan
- Abra `titan.html` no navegador ou clique em **Ver detalhes e ficha técnica** no catálogo.
- A foto é a imagem real enviada da empresa.
- A ficha técnica contém valores **A confirmar**. Edite os valores diretamente no arquivo `titan.html` quando tiver as informações verificadas.
- O botão de orçamento usa o número configurado em `script.js` e abre uma mensagem específica sobre o Titan. Troque o número de exemplo antes de publicar.
- Ao publicar no GitHub Pages, envie também `titan.html` e toda a pasta `imagens/`.
